## Recommended approach
Build the A3 spine first and ONLY the fact tier, exactly as the doc's "NEXT, fact tier first" slice prescribes — because auth (the doc's hard prerequisite) already shipped, the fact tier is now buildable immediately. Create `src/lib/learned-context/{classify.ts,store.ts}` plus a `learned_context` table, light up the dormant `pattern`/`decision` salience kinds, and wire `retrieveLearnedContext` into the ragContext seam at strategy.ts:171-184 so learned facts arrive as a labeled `<learned_context>` DATA section beside `retrievedFinancialContext` (:1088) — never as an argument to `applyDeterministicSizing` (:523) or `scanMarket`'s scoringWeights (:112). The single most important deliverable is the regression test that pins "learned_context is consumed only as advisory prompt text, never a numeric input to sizing/weights" — write it before anything else in the slice; it is the entire safety guarantee per the Safety judge. The classifier is fail-closed (UNKNOWN→risk→pending) with a conservative RISK_SUBJECTS set and intent-keyword matchers, and chat-origin candidates are hard-capped at tier `fact`. Defer the risk/strategy-directive tiers, the pending-changes queue, and the A2 prompt-block to a second slice — they carry the UI/confirmation-rail complexity and are not needed to prove the loop or the safety property. Run the structured learned_context rows in PARALLEL with the existing reflection_summary injection (do NOT gate reflection on day one) to avoid the mid-rollout starvation the doc flags.

## Risks
- Classifier mis-tier is the single security-critical chokepoint (both A3 risk notes + all three judges flagged it). A risk-adjacent phrase with no numeric trigger mis-classified as 'fact' would silently reach the prompt. Mitigated by: fail-closed UNKNOWN→risk default, conservative RISK_SUBJECTS + intent keywords, chat-origin hard-capped at 'fact', and the Phase 0 no-numeric-input regression test that makes even a misclassification unable to move sizing.
- Over-conservative classifier recreates A1's confirmation fatigue / starves behavioral learning (Efficacy judge's named failure mode). The fact tier stays fast, but tuning the line between fact and risk-adjacent is genuinely hard.
- Consumption-seam drift: a future change to applyDeterministicSizing or scanMarket could inadvertently start reading learned_context. The Phase 0 regression test is the guard — it MUST be written first and must assert sizing output is independent of learned_context contents, or the whole structural guarantee is unprotected.
- Doc line numbers are stale throughout (138-151→171-184, 439-480→523, 823→984-985). An implementer following the doc literally will edit the wrong lines. This scope corrects them; the implementer must trust the file:line evidence here over the doc.
- Reflection runs in parallel means TWO autonomous→brain channels coexist temporarily (the opaque reflection_summary AND structured rows) — acceptable per the doc but must be clearly documented so a later agent doesn't assume reflection was already replaced.
- Shared-tier rows (if enabled) inherit the shared-corpus all-user blast radius; the existing data-not-commands fence (prompt.ts) covers RAG but should be confirmed to also cover the new learnedContext section in the strategy prompt.
