# Socratic-Trade iOS App — Top-to-Bottom Review

Reviewer: DeepSeek fleet review subagent · Read-only (no repo modifications) · Base: clean checkout at origin/main `41a7a438d` (branch `deepseek/lane`)
Date: 2026-08-21 · Board reference: `board list --app socratic-trade --status open` (242 open; iOS items referenced by id below)

## Summary

The iOS app is in unusually good shape for a fleet-built native client: the model/view split is clean, every hand-mirrored route I sampled (chat, quote, symbol-desk, llm-budget, source-features, mobile commands, account deletion, push register, ack) matched its TS producer exactly, copy discipline (two-space sentences, Title Case commands vs sentence-case state words, always-inline nav titles, honest no-data rendering) is enforced by tests, and the push deep-link contract is guarded by a genuine cross-language test that the web side parses. The three known review items are partially resolved: 3b343933 (sign-out) is fixed and tested; the nested stop-loss half of 89249c60 is fixed, but the no-contract-test program remains open; 64f21332 (read-only subset) is roughly a third closed (Coach markdown, Scan header, Activity run-failure visibility). The biggest remaining risks are process-level, not code-level: the required `verify` merge gate never compiles or tests Swift, and there is no privacy manifest despite heavy UserDefaults use (an App Store release blocker the day Apple enforces it). Both `xcodebuild build` and the test-target compile pass clean on this checkout.

## Strengths

- **Architecture discipline**: `@MainActor` stores, `NavigationStack` + value-based links everywhere (never `NavigationView`), `.preferredColorScheme(.light)` forced at the app root (SocraticTradeApp.swift:41), light default honored on every screen including the login sheet and launch background.
- **API contracts verified by hand**: `FullPolicy` now decodes nested `riskRules` stop percents with top-level fallback (DeskModels.swift:368-374); `MobileSnapshot` matches `app/api/mobile/snapshot/route.ts` field-for-field (including `latestScan`, `catalog`, `needsAppConsent`); chat/quote/symbol-desk/llm-budget/source-features/commands/deletion/push payloads all line up with their routes; `OrderCancellation` and `PolicyTightening` payloads match `src/lib/mobile-api.ts` validation exactly (orderId+accountNumber stale-view guard, `expectedCurrent`).
- **Money-path hardening**: typed confirmations for live approves (`APPROVE LIVE <SYMBOL>`, matches `src/lib/strategy.ts:332`), Autopilot/CONFIRM phrases on loosening policy edits, `CommandAttemptTracker` idempotency keys, `proposalActionFeedback` settling on real placement outcomes (`filled/placed/paper`), placement `not_placed`/`busy`/`blocked` honest copy.
- **Push is production-grade**: APNs environment resolved from the embedded provisioning profile (never `#if DEBUG`), token withdrawn BEFORE cookies on sign-out, token reassignment on new sign-in, foreground banner suppression only while the SSE stream is actually up, and the cross-language `PushDeepLinkContractTests` table that `test/apns-deep-link-contract.test.ts` parses — the right pattern for the rest of the contract surface.
- **Copy**: two-space sentences verified across every Swift string literal (scan found only `Avg. Return` abbreviations); UserFacingCopyTests forbids wire enums/route names/Apple jargon; no fabricated data labels (`AccountMetrics` gates win-rate on closed-lot count, realized on fill history, unrealized on broker positions).
- **Resilience choices that are right**: Scan keeps last-good names on a 503 (`keepingLastGood`), client scan timeout (50s) outlasts the server budget (35s), SSE reconnects with 5s backoff, snapshot cache survives cold launch with the real saved-at timestamp, and account-switch commands stay available when the snapshot is stale.
- **Testing**: 15 test files / ~190+ tests; unit coverage of decode edge cases, markdown security (no remote images, no raw HTML), push payload routing, deep-link normalization, policy-tightening math, and the run-state word derivation.
