## Summary

The console is an unusually disciplined codebase: a single coalesced snapshot data layer with honest staleness labeling, server-authoritative money actions with typed-confirmation rituals, verified-wired controls from the dead-controls cluster, and an accessible-by-design shell (skip link, focus-trap stack, sr-only status). No P0 (money-path/user-blocking) defects were found. Two P1s: a legacy-pending-proposal approve dead-end (client resolves "live" from the row's stamped executionMode while the server uses the current account, so typed confirmation can never be entered — card also mislabels the account "NO ACCOUNT"), and Guardrails' Discard button not discarding the Universe group's draft (discarded edits resurface in a later commit). The rest are P2/P3 polish, a11y, copy-rule, and security-posture gaps (report-only CSP, no per-page tab titles, year-long CDN cache on legal pages).

## Strengths

- **Data honesty**: single 15s poll + SSE with deadline/abort/coalescing (useConsoleData.tsx); failures never blank screens; "delayed/fresh/aging" labels derived, not claimed; Day P&L labels stale baselines instead of hiding them; no "mock/fallback" labels on real data anywhere in scope.
- **Money-path rigor**: typed confirmations server-authoritative (409 + server `expectedText`), approve retries bounded (~3 min) with busy handling, placement outcomes reported as placed/blocked/failed, Discard/Review-and-save prompt with dirty guard wired through nav AND the account selector, policy PUTs serialized client-side to avoid read-merge-write races.
- **Verified wiring**: the three dead-controls fixes (net-of-tax toggle, webhook Send test, preset CRUD) are genuinely wired end-to-end; guardrails "Import from account" no longer arms Autopilot (moved to Strategy with run-state-preserving copy path).
- **Accessibility**: skip link + `tabIndex={-1}` main, stack-aware focus trap with focus restore, sr-only loading/status announcements, roving-tabindex scan tabs, command palette combobox pattern, light-default theme per owner rule.
- **Contrast**: all tone chips pass AA at their used sizes in both themes (verified with the repo's own contrast engine); the #2561 a11y batch is confirmed landed.
- **Freshness of data flows**: watchlist optimistic star reverts on failure; scan keeps last-good on error with labeled notices; per-page polls are visibility-gated and sane (15s snapshot, 30s watchlist, 60s/120s lessons).
