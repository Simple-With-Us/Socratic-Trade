## What landed since the 2026-08-20 audit (context, not findings)

The console improved substantially.  Fixed since DeepSeek's review: session-expiry 401 handling (`app/console/lib/api.ts:38-76` redirects to `/login` with `callbackUrl` incl. hash; full-shell takeover in `app/console/components/shell.tsx:120-140`), avatar 32px inline cap removed (`chrome.tsx:857-862`), 44px floors extended to `.con-segmented-btn`, `.con-disclosure > summary`, `.con-theme-btn` (`console.css:451-468`), disclosure `focus-visible` restored (`primitives.tsx:567`), phone chrome bar restructured into two rows so the account scope is no longer squeezed at 320px (`shell.tsx:453-489`), scan value details sheet shared with touch layouts (`scan-table.tsx:478-493`), C1/C3/C4 program items live (server snapshot cache, `TableVirtuoso`, `memo` on the five expensive cards), 15s poll with in-flight coalescing + SSE debounce + slow-request backoff (`useConsoleData.tsx`, `dashboard-request.ts`), and a shared `Saving…` mutation-busy chip (`mutation-busy.ts`).  Fonts are exemplary: self-hosted Lato via `next/font/local`, `display: swap`, latin subsets, zero network at build (`app/fonts/lato.ts`).
