# ST-4627: UI polish pass

## Context & Objective

GB-Designer asked for a contained UI, UX, and copy pass on the shipped Socratic Trade surfaces.  The goal is a small set of visible fixes that use the existing console, with before and after screenshots, and one draft pull request.  Trading logic, orders, risk, auth, and theme switching stay as they are.

## Changes Made

Phone chrome wraps onto two rows so Run Once and Start are on screen at 390px.  Desktop stays one row.  Settings section chips use Title Case, and a More sections button appears when the next chip would be clipped.  Three notification hints drop internal words.  The broker card stacks its connect buttons under the title on phones, and IBKR says Needs a gateway.  Scan controls say Market Scan, Smart Money, Refresh Scan, and Run Scan.  Orders empty and replace copy no longer says Paper or Live.  The home checklist uses plain step names.  The unconfigured login card no longer prints env var names, and the last bullet says broker passwords stay with the broker.

## Decisions & Trade-offs

`Card` gained an opt-in `stackAction` so only the broker card changes layout.  Checklist step ids (`universe`, `llm`, and the rest) are unchanged so links and tests keep working.  iOS `LoginView` already uses a different last bullet, so the web line was not copied back into Swift.  Theme switching was left to PR #5156.  The Next.js dev badge and the frozen candle wordmark are dev-server artifacts, not product bugs.  Visual baselines were not regenerated here, because `next dev` paints the N badge and would poison `test/e2e/visual.spec.ts` snapshots.  Nightly smoke should refresh them if login or the desktop console pixels move.
