# 2026-08-28 - qdrant-st

## Summary

Owner-directed: the shared Hetzner box was upgraded to double capacity and Qdrant now runs on it as the self-host path for ST's RAG (Plan A of the 2026-08-27 fleet ops review).  Coolify service `qdrant-st` (image `qdrant/qdrant:v1.19.0`), port 6333 bound to the server's Tailscale mesh IP only — no public FQDN, no Traefik route — API-key required, capped at `mem_limit 6g` / `cpus 3` so prod trading is never starved. The full non-Voyage corpus was copied the same day: 801,239 points, verified.

## Why

Pinecone's Standard trial is in its owner-designed early-snap buffer (real end ~2026-08-30); the fleet review's Plan A sequencing calls for a self-host landing zone plus condense-first before any store decision is final.  Owner rule for the copy: ALL non-Voyage embeds.  Records without `embed_model` metadata are voyage-era legacy — invisible to current bge-m3 retrieval (its filter requires the field) — so the copy keeps exactly the records retrieval can see today and drops `voyage-*` plus untagged legacy (0.95% + 95 records).

Snapshot semantics: the copy reflects Pinecone as of the run.  Writes landing during/after are not in Qdrant; point ids are deterministic (`uuid5("st:" + namespace + ":" + pinecone_id)`, original id in payload `pc_id`), so a re-run is an idempotent delta pass.  A delta pass MUST be run immediately before any retrieval cutover, and ongoing dual-write belongs to the storage-adapter lane, not this script.

## Files

- `scripts/qdrant/pinecone-to-qdrant-copy.py` — stdlib-only, resumable copier.  Fetch batches are sized by ENCODED URL length (corpus ids are 155 chars; ~99-id GET fetches hit HTTP 414), upserts use `wait=true` (applied, not just acknowledged), pagination checkpoints persist only after every queued batch up to that cursor completed, failed batches retry in halves, a namespace with failing batches is never marked done, and the process exits nonzero if failures remain.  State files are bound to their index/collection pair and refuse a mismatched resume.
- `docs/rollouts/2026-08-28-qdrant-st.md` — this doc.
- `docs/EFFORT-LOG.md` — row for this unit.
