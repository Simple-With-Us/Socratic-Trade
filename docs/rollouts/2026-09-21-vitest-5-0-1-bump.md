  release, so no test-config or suite changes are needed.

  timeline, or approach.
- **Classified runtime deploy material (correction).**  An earlier revision of this note claimed
  a devDependency-only change is not a production deploy.  That was wrong: Coolify's `watch_paths`
  matching is file-based and does not distinguish `devDependencies` - this commit changes
  `package.json` + `package-lock.json`, which **are** watched, so merging starts a production image
  build (or a weekday RTH refusal followed by the drain), exactly like the runtime bumps in this
  lane.  Corrected per Codex P1.
