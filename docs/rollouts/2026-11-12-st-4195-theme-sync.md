# ST-4195: one dark-mode switch

## Context & Objective

Dark mode was painted by two mechanisms that could disagree: the `.dark` class and a `data-theme` attribute.  Public tokens and Tailwind `dark:` followed the class.  Console tokens followed `data-theme`, and a second copy of those tokens followed `prefers-color-scheme` whenever the attribute was missing.  A saved dark choice could flash the console light, and an explicit light choice could still go dark with the OS.  This keeps both signals and writes them from one function.

## Changes Made

`applyDocumentTheme` sets `html` `.dark`, `html` `data-theme`, every `.console-root` `data-theme`, and `theme-color` to the same resolved light or dark value.  The boot script calls the same steps before first paint.  `ThemeProvider` uses it on mount and on system-preference changes, before paint.  Console `data-theme` is that resolved value, including when the stored choice is system.  The console dark token block is one rule selected by `html.dark`, `html[data-theme=dark]`, and `.console-root[data-theme=dark]`.  The media-query copy is removed.  Tailwind `dark:` matches both signals.  The root error page uses the same binder instead of an OS-only media query.  The CSP hash of the boot script is updated.

## Decisions & Trade-offs

Both signals stay.  Readers did not all move onto one of them, because Tailwind `dark:` is class-based and console tokens are attribute-based.  The setter is the source of truth, and each CSS rule lists both selectors so the token values cannot diverge.  System preference is resolved in JavaScript and then written as an explicit light or dark.  There is no second CSS media-query palette.  Default remains light when storage is missing, unknown, or denied.  GB-Designer already holds the Linear claim, so this seat did not take it.  No trading, order, sizing, or risk code changed.  No phase doc describes this switch.

## Zero-Code Findings

Charts do not read `.dark` or `data-theme` themselves.  Sonner takes `resolvedTheme` from the same provider.  The old `console:theme` storage key is already gone on main.  The desync that remained was the console attribute staying unset in system mode, the boot path not repainting console roots, and the duplicated media-query palette.
