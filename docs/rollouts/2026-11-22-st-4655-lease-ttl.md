# ST-4655 scheduler lease TTL derived from the watchdog budget (2026-11-22, Muse Code MC)

## Context & Objective
ST-4650 fleet-sweep Batch B: the scheduler leader-lease default TTL (90s) was shorter than the tick-watchdog budget (120s), and lease renewal runs on the same process's interval timer.  A tick body that pinned the event loop (sync SQLite) therefore blocked renewal, the lease expired at 90s while the watchdog still considered the tick alive, and a second process during deploy overlap could steal leadership mid-tick.

## Changes Made
- New `src/lib/scheduler-timing.ts` (import-free, avoiding a scheduler <-> scheduler-lease cycle): `DEFAULT_TICK_WATCHDOG_MS` (120s), `TICK_WATCHDOG_POLL_MS` (15s), `LEASE_TTL_GRACE_MS` (60s), `schedulerTickWatchdogLimitMs()`, and `schedulerLeaseTtlMs()` = effective watchdog budget + grace (180s default).  An explicit valid `SCHEDULER_LEASE_TTL_MS` still wins untouched; an invalid value falls back to the derived default.
- `src/lib/scheduler-lease.ts`: TTL resolution now delegates to `schedulerLeaseTtlMs()`; header keeps the two-process TOCTOU limitation honest and notes TTL arithmetic alone can no longer depose a live leader.
- `src/lib/scheduler.ts`: imports and re-exports the timing constants/helpers so existing importers and tests are unchanged; stale 90s comments updated.
- `test/scheduler-lease.test.ts`: construction equality (TTL = watchdog + grace), explicit override wins, raising the watchdog env raises the derived TTL, a 100s no-renewal stall is not stealable, 15s-poll renewal holds leadership to 300s, and steal still works after finite TTL expiry.

## Decisions & Trade-offs
- Derived TTL chosen over lease-generation fencing on money-path writes: fencing is a larger, riskier change to live-money paths and is not needed to close the TTL-arithmetic gap.  The pre-existing two-process TOCTOU window remains, documented in the lease header.
- The boot-binary checksum half of ST-4655 is intentionally untouched; it needs its own staged rollout so a bad pin cannot take production down at boot.
