# ST-4658 API hardening smalls (2026-11-22, Muse Code MC)

## Context & Objective
ST-4650 fleet-sweep API batch: cross-tenant SSE leakage by omission, an unauthenticated audit-flood path, unbounded settings writes from a buggy/compromised session, and body parsing before identity on order-adjacent routes.

## Changes Made
- `src/lib/events.ts` + both SSE routes (`app/api/events/stream/route.ts`, `app/api/mobile/events/route.ts`): `GLOBAL_DASHBOARD_EVENT_TYPES` = {`dirty`, `market-data`} and `shouldDeliverDashboardEvent` — tagged events reach only their owner, untagged events reach everyone only when allowlisted.  Every untagged emit site at the base commit was enumerated (regime-watch, admin emit-test, history shared-cache fill); all other producers tag `userId`.
- `src/lib/rate-limit.ts` + `app/api/webhooks/tradingview/route.ts`: `tradingviewWebhookUnauth` 60/60s mirrors `congressWebhookUnauth`, enforced before the rejection audit write on both IP and secret rejections.  Secret/IP semantics and client-IP trust are untouched.
- `app/api/keys/route.ts` (POST+DELETE), `app/api/policy/route.ts` (PUT): `settingsWrite` 30/min per user after identity (policy: before symbol-quote checks and the live broker verification).  `app/api/notifications/test/route.ts`: `notificationTest` 10/min.
- `app/api/mobile/commands/route.ts`, `app/api/proposals/[id]/approve/route.ts`: identity + rate limit resolve before `request.json()` (identity reads middleware headers only; happy-path shapes/statuses unchanged).
- Tests: `test/dashboard-event-tenant-filter.test.ts` (new), `test/write-route-rate-limits.test.ts` (new), `test/webhooks-tradingview.test.ts` (flood case: 60 audited 401s, 61st 429 with no audit row).

## Decisions & Trade-offs
- Fail closed on untagged events: a future emitter that forgets `userId` loses its broadcast rather than leaking across tenants.  The cost is that a genuinely global new event type must be added to the allowlist deliberately.
- Bounds sit far above human use (30 settings writes/min, 10 test notifications/min) so they contain only loops/bots, never the owner.
- Out of scope by design: the 47-route bounded-JSON migration, four-shape error unification, and the keys/policy full parse-before-identity reorder (their bounded parsers predate this change; only limit placement was added there).
