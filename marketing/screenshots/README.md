# Marketing Screenshots

Organize source captures by platform under `macos/`, `ios/`, and `web/`, with working files in `drafts/`.  Preserve original captures.  A screenshot is a draft until an owner-approved release process records its approval.

Name files `<product>-<platform>-<surface>-<build>-<locale>-<state>.<ext>` using lowercase ASCII and hyphens.  Add a same-stem `.md` sidecar with capture date, app/build, device or viewport, OS/browser, appearance, and intended use.  Never edit an original capture in place.
